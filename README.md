# Сервис автоматизации препродакшн-документации для съёмки

## Описание решения  
Мы создаём сервис, где пользователь загружает стандартизированный сценарий на русском языке в формате .pdf или .docx - тут еще txt добавить

пользователь может выбрать готовый пресет (Базовый, Расширенный, Полный анализ) - не совсем такое есть, у нас можно выбрать либо только базовые столбцы, либо сразу все, либо да, выбрать отдельные стоблцы.

### Основные шаги обработки:
1. Загрузка документа пользователем (формат `.pdf`, `.txt` или `.docx`).  
2. Автоматическое распознавание номеров сцен и сегментация текста по сценам.  
3. Анализ каждого сегмента с определением:  
   - локации (пример: «кабинет», «улица»)  
   - времени суток  
   - основного и второстепенных персонажей  
4. Далее инструмент выявляет такие элементы, как:  
   - массовка (например: «толпа», «официанты»)  
   - реквизит (например: «автомобиль», «животное»)  
   - сложные элементы съёмки (грим, каскадёры, спецэффекты)  
5. Автоматическая агрегация извлечённых данных в структурированную таблицу:  
   - каждая строка соответствует отдельной сцене  
   - столбцы содержат распознанные производственные элементы  
6. Универсальность структуры:  
   - пользователь может выбрать готовый пресет (Базовый, Расширенный, Полный анализ)  
   - или настроить собственный набор столбцов (например: «транспорт», «спортивный инвентарь», «музыкальные инструменты»)  
   - это позволяет адаптировать результат под специфику конкретного проекта  
7. Финальный этап — экспорт результатов в таблицы CSV или XLSX в выбранном формате.

### Установка  
Сборка через Docker

```bash
git clone https://github.com/jenbefishy/wink-ai-challenge
cd 'wink-ai-challenge/app'
docker build -t wink-bot .
```
Запуск:
```
docker run -d \
  --name wink-bot \
  -e TELEGRAM_BOT_TOKEN="8545025516:AAF4Y-3cIChf6cAPnCOivsG1W-MXkQURFrw" \
  -v wink-models:/app/models_v5 \  # Для сохранения моделей между запусками
  -v wink-temp:/app/temp_bot_files \
  wink-bot
  ```
